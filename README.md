## Step 1 — Fork this repository

Click the **Fork** button at the top right of this page, then **Create fork**.

Check the URL. It should now say:

```
github.com/YOUR-USERNAME/apcsa-00-setup
```

If it still says the class organization name, you are still looking at my copy. Go back and click Fork.

> **Fork** = make your own copy of someone else's project. You can change your copy however you like and it will never affect the original.

---

## Step 2 — Edit your files

You have two options, and both are fine:

**Option A — Edit right here on GitHub (easiest for now)**
1. Click the file you want to edit
2. Click the ✏️ pencil icon
3. Type
4. Scroll down, write a **commit message**, click **Commit changes**

**Option B — Edit in a codespace (what we'll use once we start coding)**
1. On **your fork**, click the green **Code** button → **Codespaces** tab → **Create codespace on main**
2. Wait for VS Code to load in your browser
3. Edit, then use the **Source Control** panel in the left sidebar to commit and push

---

## Step 3 — Commit properly

You need **at least three separate commits** on this assignment. Not one big one.

**Good commit messages:**
```
Add hello-world intro section
Add table of favorite apps
Fix broken link in profile
```

**Bad commit messages:**
```
stuff
asdf
done
final FINAL v2
```

Write the message so that *you, six months from now, at 11 PM* would know what you changed without opening the file.
