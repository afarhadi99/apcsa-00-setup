# Account Setup — Step by Step

Print this if you need to. Work through it in order. Every account here is free, and there are fewer of them than you might expect — the place you write Java is part of GitHub, not a separate signup.

---

## 1. Google Classroom

1. Go to [classroom.google.com](https://classroom.google.com)
2. Sign in with your **school** Google account
3. Click the **+** in the top right → **Join class**
4. Enter the join code your teacher wrote on the board
5. ✅ You should see "AP Computer Science A"

---

## 2. GitHub

1. Go to [github.com/signup](https://github.com/signup)
2. Enter an email you can actually check right now
3. **Choose your username carefully.**

   This is public. It will appear on every project you build this year, and it is the link you may one day send to a college or an employer.

   | Good | Not good |
   |---|---|
   | `sarah-levy` | `xXgamerXx2010` |
   | `dcohen-codes` | `idkwhatimdoing` |
   | `arielm22` | `hahaha123` |

   You can change it later, but it breaks all your old links. Pick once.

4. Verify your email — check spam if it doesn't arrive within a minute
5. Skip the personalization survey (or fill it in, it doesn't matter)
6. ✅ You should land on your GitHub dashboard

**Write your username down.** You will need it constantly.

This is the only coding account you need. The editor you write Java in — GitHub Codespaces — is part of GitHub, not a separate service. Step 3 is where you open it.

---

## 3. Open your first codespace

A codespace is a full VS Code editor that runs in your browser, attached to one of your repositories. You don't install it and you don't sign up for it. You open it from a repo.

1. Go to any repository you own — your fork of `apcsa-00-setup` works, once you've forked it
2. Click the green **Code** button at the top right
3. Click the **Codespaces** tab
4. Click **Create codespace on main**
5. Wait. The first one takes a minute
6. ✅ You should be looking at VS Code in your browser, with your repo's files in the left sidebar

**When you're done working, stop it.** Click the codespace name in the bottom left corner → **Stop Current Codespace**. GitHub gives you a monthly free quota of Codespaces hours, and a codespace left running spends it while you do nothing. Stopping does not delete anything.

Full details are in [codespaces-guide.md](codespaces-guide.md). You do not need to read it today.

1. Go to [code.org](https://code.org)

1. Go to [myap.collegeboard.org](https://myap.collegeboard.org)
2. Sign in with your College Board account (create one if you don't have one)

## Troubleshooting

| Problem | Fix |
|---|---|
| Verification email never arrives | Check spam. Still nothing? School filters sometimes block them — use a personal email for GitHub instead |
| "Username already taken" | Add a middle initial or a short number. Don't spend more than 60 seconds on this |
| No **Codespaces** tab under the Code button | You're on a repo you don't own, or you're not signed in. Codespaces opens on **your** repos — fork first |
| The codespace is taking forever to start | The first one is the slow one. Give it two minutes before you assume it's broken |
| School laptop blocks a site | Tell your teacher immediately — it needs to go to IT, not be worked around |
